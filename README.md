##  Project Overview
A Python program that implements the Caesar Cipher
to encrypt and decrypt any text message using
a shift key chosen by the user.

---

##  Goal
Implement a simple encryption and decryption 
technique to understand data confidentiality 
and cryptographic logic.

---

##  Features
- Encrypts any text message
- Decrypts encrypted text back to original
- User can choose their own shift key
- Handles uppercase, lowercase, spaces and symbols
- Verifies encryption and decryption match

---

##  Tools Used
- Python 3.13
- VS Code

---

## How to Run
```bash
python encryption.py
```

---

##  How Caesar Cipher Works
Encryption: E(x) = (x + n) % 26
Decryption: D(x) = (x - n) % 26
Example with shift 3:
A → D
B → E
Hello → Khoor
